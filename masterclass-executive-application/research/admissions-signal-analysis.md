# Admissions Signal Analysis

Status: NOT STARTED — produced in Phase 1 (Discover) alongside the program fit brief.

Purpose: translate the program research into a signal matrix the story-strategist can score against.

Required content:

- Signals the application prompt explicitly tests (beyond responsibility, real system/process/algorithm, explicit curiosity, motivation shift, personal meaning)
- Signals the program likely values implicitly (operator credibility, systems thinking, applied learning, executive maturity, authenticity)
- Anti-signals (achievement summaries, generic leadership language, AI-sounding prose, inflated claims, confidential detail)
- Weighting rationale feeding the story-strategist's scoring matrix
- Facts vs. inference clearly separated
